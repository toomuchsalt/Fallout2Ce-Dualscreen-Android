Fallout 2 on Armada

A graphical setup for the AYN Thor. No terminal, Linux package installation, administrator password, or changes to Armada's system files are required.

You need your own complete Fallout 2 game installation. The download does not include the game. Copy the complete game folder from your computer; do not select a Windows installer or an APK.

Install

  1. Switch to Desktop Mode. In Steam, open the Steam menu, choose Power → Switch to Desktop. Open the folder-shaped Files application (Dolphin).
  2. Put your game folder somewhere permanent. For example, open Home, create a folder named Games, and copy the entire Fallout 2 folder into it. Inside the game folder you should see master.dat, critter.dat, and its other files and folders. Keep all of them together. Your existing mods and saves may stay with this folder.
  3. Extract the download. Use the Armada .tar.gz download from the release page. In Downloads, right-click it (or press and hold), choose Extract → Extract archive here, and open Fallout2-Armada. If you downloaded an Actions artifact ZIP, extract that ZIP first, then extract the .tar.gz inside it.
  4. Double-click “Install Fallout 2”. Choose Run if Files asks. This is the application with that name, not a file inside bin or share. If Files says it is not executable, right-click it, open Properties → Permissions, tick Is executable, then open it again.
  5. Choose your game folder. Click Choose game folder, select the permanent Fallout 2 folder from step 2, and confirm. Choose the folder itself, not master.dat. If files are missing, setup explains what to choose.
  6. Play. After “Setup complete”, open the desktop application menu, choose Games → Fallout 2 (Armada). You may now delete the downloaded archive and its extracted folder from Downloads. Keep your separate game folder.

Add it to Steam Game Mode

  1. In Desktop Mode, open Steam.
  2. Choose Games → Add a Non-Steam Game to My Library (or Add a Game → Add a Non-Steam Game).
  3. Tick Fallout 2 (Armada) and choose Add Selected Programs. If it is not listed, close and reopen that window; if needed, restart Steam.
  4. Open its Properties → Compatibility. Leave Force the use of a specific Steam Play compatibility tool unchecked. This is a native Armada application; it does not use Proton.
  5. Return to Game Mode using the desktop's Return to Gaming Mode shortcut. In Steam, open Library → Non-Steam → Fallout 2 (Armada) → Play.

Tap a text field to open Plasma Keyboard in Desktop Mode or Steam’s keyboard in Game Mode. Steam controls its keyboard’s screen placement; the game cannot select the bottom screen for it.

Updates, game-folder changes, and removal

Update: Close the game. Download and extract the new Armada archive, then run its Install Fallout 2 and choose the same game folder. Setup updates its application copy while retaining your game files and saves. The Steam shortcut continues to work.

Choose a different game folder: In the desktop application menu, right-click Fallout 2 (Armada) and choose Choose game folder, or run Install Fallout 2 again.

Uninstall: In the desktop application menu, right-click Fallout 2 (Armada) and choose Uninstall application (keep saves). Remove its Steam shortcut through Steam separately. The original game folder and saved games are kept.

If something goes wrong

  • Missing game files: Copy the complete installed game folder, not just its Windows installer, shortcut, or two archive files. The folder picker needs the folder that directly contains master.dat and critter.dat.
  • Read-only game folder: Copy it into Games in Home and choose that copy. You do not need to unlock Armada or install any Linux packages.
  • No second-screen UI: Wake the device, confirm both displays are enabled in the desktop's Display settings, and check the game's Settings → Display → Dual screen. Restart the game after changing the desktop display layout.
  • Game folder moved or deleted: Choose its new location through the application menu's Choose game folder action.
  • Setup says the application is running: Close Fallout 2 and any other setup window, then retry.

Menu wording can vary slightly by Armada version. Desktop and Steam-menu references: Valve's Desktop FAQ. This package uses only your home folder and tools already present in Armada's KDE desktop.
